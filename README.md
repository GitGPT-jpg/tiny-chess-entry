A compact alpha-beta chess engine in under 4 KB of Python: 0x88 board, transposition table, killer moves, MVV-LVA ordering, quiescence search and iterative deepening on a fixed node budget. Built for make.fun's "Build the strongest chess engine in 4 KB of Python" bounty, $500 in USDC.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 -P -s main.py
```
